# 🪒 Yak Shave Launcher

A lightweight, no-bullshit tool to manage and launch your local Python automation scripts.

A control centre for your own scripts. Point it at a folder, and every script
in there shows up as a card: searchable, sortable, categorised, one click
from running. Drop in a new script and it appears — nothing to register,
nothing to configure, no edits to the launcher itself.

This is the **launcher only** — the free frame every Yak Shave tool runs in.
Individual tools are released separately.

## Features
- Fast and clean UI / CLI interface
- Automatically detects new scripts in your tools directory
- Zero unnecessary dependencies
